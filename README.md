# Foxy — Render Test

هذه نسخة اختبار أولية لموقع Foxy:
- واجهة عربية افتراضيًا مع تبديل عربي/إنجليزي.
- تصميم أسود وأصفر متجاوب مع حركات CSS.
- أدوات تعمل داخل المتصفح: منسق نصوص، مولّد كلمات مرور، عداد حروف وكلمات، ومؤقت.
- لا تحتاج قاعدة بيانات لتشغيل النسخة التجريبية.

## النشر على Render (Static Site)
1. فك ضغط `Foxy_Render_Test.zip`.
2. ارفع محتويات المجلد إلى مستودع GitHub جديد.
3. في Render اختر **New + → Static Site** ثم اربط المستودع.
4. اترك **Build Command** فارغًا، واجعل **Publish Directory** هو `.` (النقطة).
5. اضغط Deploy. Render سيعطيك رابطًا عامًا ينتهي بـ `onrender.com`.

## ملاحظات
هذه نسخة واجهة/اختبار وليست لوحة إدارة متكاملة. إعدادات الإدارة، حسابات المستخدمين، المنتجات الديناميكية، وقاعدة البيانات تحتاج تطويرًا إضافيًا قبل استخدامها إنتاجيًا.
